# Release records

- `HUMAN_RELEASE_CHECKLIST.md` lists the decisions that need approval before release.
- `EVIDENCE_BUNDLE.zip` and `EVIDENCE_BUNDLE.sha256` are a deterministic archive of the paper, proof, Lean files, verification and audit summaries.
- `RELEASE_NOTES_v1.0.0.md` and `RELEASE_NOTES_v1.0.1.md` are the release notes. `PUBLISH_v1.0.0` and `PUBLISH_v1.0.1` are the markers that triggered the release workflow.
- `RELEASE_ASSET_SHA256SUMS.txt` lists the SHA-256 of every downloaded Version 1.0.1 release asset.
- `DOI_DEPOSIT.md` and `BADGE_ACTIVATION.md` record the Zenodo deposit and the badge checks. `BRANCH_PROTECTION.md` is added when the protection rule is verified.
