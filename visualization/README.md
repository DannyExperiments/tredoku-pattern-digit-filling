# Tredoku filling explorer

An interactive 3D figure for the proof. Download [`tredoku-filling-explorer.zip`](tredoku-filling-explorer.zip), unzip it, and open `index.html` in a browser. It runs offline with no external libraries.

- **The pattern** is a genuine tredoku pattern: 12 diamonds and 7 runs of three, and every one of those runs bends. It is drawn in 3D as the stepped surface it represents. Drag to rotate.
- **Click any cell** to highlight its diamond and the line or lines through it. Each line follows a run of three diamonds across shared edges, bending where the diamonds change orientation, and contains 1–9 exactly once.
- **Switch the offsets to "All zero"** to see why the run offsets are needed: lines then repeat digits.
- **Colour by digit** to see each diamond as a 3×3 Latin square.
